{{ icon('send') }} Webhook Setup

Add webhook calls to your backup scripts to track status. Use localhost for scripts running on the VPS, or the public URL for remote scripts (e.g. NAS pull).

Every call must send the X-Webhook-Secret header; without it the webhook answers 401/403 and nothing is recorded. Set the secret under Settings → Advanced → Backup and replace YOUR_WEBHOOK_SECRET below with it. The local example assumes the default bind address 127.0.0.1:5050; if the app runs with a different VPS_MANAGER_HOST / VPS_MANAGER_PORT, use those instead.

VPS backup script (localhost)
WEBHOOK_URL="http://127.0.0.1:5050/api/backup/webhook"
WEBHOOK_SECRET="YOUR_WEBHOOK_SECRET"

# Report success:
curl -s -X POST "$WEBHOOK_URL" \
  -H "Content-Type: application/json" \
  -H "X-Webhook-Secret: $WEBHOOK_SECRET" \
  -d '{"status": "success", "details": "Backup completed"}'

# Report failure:
curl -s -X POST "$WEBHOOK_URL" \
  -H "Content-Type: application/json" \
  -H "X-Webhook-Secret: $WEBHOOK_SECRET" \
  -d '{"status": "failure", "details": "Error message"}'
Remote pull script (NAS / offsite)
WEBHOOK_URL="{{ request.url_root }}api/backup/webhook"
WEBHOOK_SECRET="YOUR_WEBHOOK_SECRET"

# Same format and header, over the public HTTPS URL.
# No extra ports needed — connects via existing HTTPS.
curl -s -X POST "$WEBHOOK_URL" \
  -H "Content-Type: application/json" \
  -H "X-Webhook-Secret: $WEBHOOK_SECRET" \
  -d '{"status": "success", "details": "NAS pull completed"}'
